# SOC Intelligence Orchestrator

Projeto modular de inteligencia aplicada a operacoes
de seguranca (SOC), utilizando n8n, Python,
LangChain e PostgreSQL.

## Objetivo

Desenvolver um motor de orquestracao capaz de:

- Coletar eventos.
- Normalizar os dados recebidos.
- Identificar duplicidades.
- Detectar novas evidencias relevantes.
- Correlacionar eventos.
- Executar analises assistidas por IA.
- Produzir relatorios tecnicos estruturados.
- Manter historico e auditoria.

## Workflows planejados

WF-00 - Orquestrador Central
WF-01 - Coleta de Eventos
WF-02 - Normalizacao e Deduplicacao
WF-03 - Contexto e Correlacao
WF-04 - Motor de Inteligencia Artificial
WF-05 - Validacao e Relatorios

## Estrategia inicial

A primeira versao sera desenvolvida em laboratorio,
utilizando exclusivamente eventos sinteticos.

Nenhuma integracao corporativa sera ativada nesta fase.

## Versionamento

O primeiro commit sera realizado somente depois
da validacao das etapas iniciais do projeto.
